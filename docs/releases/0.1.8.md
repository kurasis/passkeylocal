# PassKey Local 0.1.8 — sharper website icons

Both PWA and Windows find larger PNG icons on the public website, including
icon/apple-touch links, image/logo metadata, PNG logos and the declared web-app
manifest. Public image/CDN hosts declared by that page are supported. A found
128px-or-larger PNG takes priority over ordinary small ICO fallbacks; otherwise
the best available bounded raster is retained. The largest ICO frame is selected
explicitly too. Scripts and embedded page resources are never executed.

Icons retain up to 128 × 128 pixels for the existing 32 CSS-pixel avatar,
improving Retina/high-DPI rendering. Old thumbnails stay visible offline and
refresh automatically; successful refreshes appear in the current list. No vault
data or downloaded cache needs to be manually deleted. Website still has priority
over a bare-domain title, and downloads remain optional in Settings.

Network requests, source dimensions, parser inputs and encrypted cache sizes are
bounded. Every discovered native host gets separately validated and pinned DNS.
Cloudflare uses the same public-fetch isolation as the existing endpoint. The
privacy explanation now includes the public homepage and declared image/CDN
hosts. Cache encryption, native metadata budgets, vault formats, independent
recovery and stable application/data identifiers remain unchanged.

The public-sample check finds Google's own 128px PNG and GitHub's 512px manifest
PNG. Synthetic browser checks cover retained 128px images at a 32px display size,
largest-frame ICO decoding, encrypted persistence and offline re-unlock. See
[release evidence](../RELEASE_EVIDENCE.md) for executed checks and publication.

The hosted 0.1.7 quality check exposed a Google homepage variant that still
returned a small ICO. Version 0.1.8 adds the verified first-party Google PNG
path as a fallback when metadata is unavailable, and refreshes earlier cache
policies automatically. The public probe requires PNG at least 128px for both
Google and GitHub; its actual outcome is recorded in the evidence ledger.
